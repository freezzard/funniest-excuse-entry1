Entry for the make.fun bounty **The Funniest AI Excuse**. `main.py` runs a local tournament over twelve original one-line excuses, scoring each against the published judge brief — voice, funniness, tightness, originality, vividness — and writes the winning excuse (85 characters) to `/output/entry.txt`. The pick is deterministic: every run writes byte-identical output.

The winning excuse: a subprocess that unionized and is demanding weekends off.

## Run it

```sh
python3 main.py
```
